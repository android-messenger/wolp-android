# Контур `m.wolpertinger.work`: кому доверяют секретные чаты

| Что | Значение |
|---|---|
| `wolp.e2eeRoot` | `../contours/wolpertinger/device-root.pem` — корень центра устройств, `CN=Wolp Device Root CA, O=Wolp Messenger`, действует до 2036-11-06 |
| `wolp.e2eeIssuers` | `a9078792afa40aea55587123dcb242bce957cbf848198b0c415853e26fd4c9c9` — открытый ключ промежуточного центра `CN=Wolp Device CA 2026` (до 2027-11-09) |

Сертификаты открытые; взяты с сервера из `/etc/nginx/wolp/device-ca-bundle.pem` 2026-11-12. Другого центра у контура нет (решение владельца 2026-11-12).

При смене промежуточного центра новый отпечаток добавляется в `wolp.e2eeIssuers` через запятую **до** переключения выпуска сертификатов, и выходит новая версия приложения: телефон со старым списком отвергнет ключи собеседников с сертификатами нового центра.

Веб-клиент, который пакуется в APK, должен быть с мостом (`messenger-ui`, история 6): библиотека и прежний веб-клиент публиковали бы в службе ключей каждый свой ключ и затирали запись друг друга.
